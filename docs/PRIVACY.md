# RoadVision 隐私与数据处理原则

## 1. 默认行为

-   视频帧、检测结果、车牌识别默认仅在设备本地处理。
-   首阶段不自动上传视频、帧、车牌或事件数据。
-   默认不把原始视频帧持久化到磁盘。
-   诊断日志不记录完整车牌、原始帧或不必要的个人信息。
-   用户应能停止采集并删除本地事件记录。

## 2. 未来主动上传功能

如未来增加上传功能，必须同时具备： 1. 用户主动发起，默认关闭。 2.
上传前明确展示数据类别、用途、接收方和保留期限。 3.
用户可取消上传；网络失败不会悄悄改为后台重试上传。 4.
最小化上传，只传完成目的所需的数据。 5.
访问控制、传输保护、服务端保留/删除规则和审计。 6.
上传历史可查看，适用时支持删除。 7.
在隐私政策、权限说明和产品界面中保持一致。

## 3. 车牌与视频处理

车牌、视频画面和时间戳可能涉及可识别个人或车辆的信息。测试人员应使用有合法处理依据的素材，并限制访问权限和保留期限。测试报告尽量使用脱敏编号和统计数据。

用户主动导出的 JSON 诊断报告包含本地事件中的车牌文本、设备型号、系统构建和模型 hash。导出仅写入应用缓存并经系统分享面板交给用户选择的目标，不自动上传；测试人员应按内部数据要求保管和删除报告文件。

## 4. Android 权限与后台运行

-   摄像头权限应在实际使用前说明用途。
-   后台/熄屏持续采集必须遵守目标 Android
    版本的前台服务、运行时权限和通知要求。
-   用户必须可以明确停止采集。
-   不得绕过系统权限、隐私提示或厂商安全机制。
-   荣耀 MagicOS 的后台限制以目标机型实测为准。

## 5. 隐私验收

-   [ ] 首阶段网络抓包确认没有非预期上传
-   [ ] 日志检查确认没有完整车牌或原始帧泄露
-   [ ] 本地记录可删除
-   [ ] 停止采集后摄像头资源释放
-   [ ] 如启用上传，单独完成告知、同意、取消、删除与安全审查
