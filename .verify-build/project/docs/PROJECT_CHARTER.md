# RoadVision 项目立项文档

## 1. 项目概述

**项目名称：** RoadVision\
**项目类型：** Android 端侧道路视觉感知原型\
**阶段：** 第一阶段技术验证与内部测试\
**交付物：** 可安装的内部测试
APK、源代码、模型与许可证清单、真机测试报告、已知问题清单。

RoadVision
使用手机摄像头采集道路视频，在设备本地执行车辆检测、车道识别、车辆跟踪及车牌检测/OCR，并以画面叠加和事件列表呈现结果。

## 2. 背景与目标

项目旨在验证普通 Android
手机在受控测试条件下进行持续道路视觉感知的可行性，并为后续产品化提供可复现的性能、准确率、许可证与隐私依据。

### 可验收目标

1.  CameraX 持续采集并向推理流水线提供帧。
2.  画面中展示车辆检测框、车辆跟踪 ID 和车道线。
3.  对符合触发条件的车牌执行检测与 OCR，并展示识别文本、置信度及时间。
4.  默认本地处理，事件记录存储于本机。
5.  在预先选定的荣耀真机和书面测试条件下，目标为持续稳定 15 FPS。
6.  形成可审计的许可证审查记录及端侧性能测试报告。

"持续稳定 15 FPS"须在项目中定义统计口径。建议验收窗口为连续 30
分钟，另做 60--120 分钟稳定性扩展测试；记录有效处理 FPS、端到端延迟
P50/P95、丢帧、温度/热状态、内存和耗电。15 FPS
是否达到，只能由目标设备实测判定。

## 3. 范围

### 本阶段包含

-   Android 工程与内部构建流程。
-   CameraX 采集、帧旋转/裁剪和背压控制。
-   ONNX Runtime 推理适配层。
-   车辆检测、车道识别、车辆跟踪。
-   车牌检测、裁剪/矫正、OCR、多帧结果融合。
-   画面叠加、识别事件列表、置信度与时间显示。
-   本地事件存储和用户主动删除。
-   设备诊断、日志脱敏、性能与热稳定性测试。
-   许可证、模型来源和第三方依赖审查。

### 本阶段不包含

-   公开商店发布与面向公众的 SLA。
-   自动上传视频或后台云端分析。
-   账号、车队管理、云端仪表盘。
-   精确测速、精确距离估计、碰撞责任判定。
-   自动驾驶控制或安全关键预警。
-   以未经授权的数据训练或微调模型。

## 4. 关键约束

-   **闭源商业目标：** 模型与依赖授权是准入门槛，不是发布前补充工作。
-   **设备未知：**
    荣耀具体型号尚待确定；在设备确定前，性能结果只能作为实验方案，不能作承诺。
-   **功耗与温升：** 15 FPS
    目标必须与连续运行、温控降频、耗电和系统后台限制一起评价。
-   **隐私：**
    默认本地处理；任何未来上传功能必须由用户主动触发并有明确告知与控制。
-   **模型可替换：** 车辆、车道、车牌和 OCR
    模型通过接口隔离，避免被单一模型供应方锁定。

## 7. 验收原则

-   功能验收与性能验收分开。
-   每个指标标记为"目标""估算"或"实测"。
-   实测报告必须包含设备型号、Android/MagicOS
    版本、构建号、模型版本/hash、推理提供器、输入分辨率、测试视频/场景、环境温度、持续时间和原始日志。
-   若目标设备无法持续达到 15
    FPS，应记录实测值、瓶颈与建议的降级策略，不得通过修改统计口径宣称达标。
-   许可证存在未解决的闭源分发风险时，不得发布给外部用户。

## 8. 主要风险

  -------------------------------------------------------------------------------------------------------------
  风险                           影响                    应对
  ------------------------------ ----------------------- ------------------------------------------------------
  模型许可证不兼容闭源商业用途   不能合法分发            M0 完成代码/权重/数据/依赖逐项审查；准备替代模型

  荣耀机型性能不足或热降频       无法持续 15 FPS         早期真机基准；分级推理、降分辨率、OCR 按需触发

  车牌 OCR 易受运动模糊/反光影响 识别率低                多帧融合、质量门控、置信度展示，不输出无依据确定结果

  后台/熄屏限制                  长时间运行不稳定        前台服务与权限合规设计；按具体 MagicOS 版本实测

  隐私数据意外外传               用户信任与合规风险      默认离线、网络审计、脱敏日志、上传需主动确认

  热/耗电过高                    实用性不足              记录温度/耗电，限定持续测试窗口，评估降级方案
  -------------------------------------------------------------------------------------------------------------
